# Development Phases

## Phase 1 — Backend Fundamentals

* Spring Boot
* Spring Security
* Testing (JUnit, Mockito, Spring Boot Test)
* PostgreSQL
* REST APIs

**Goal:** Build a secure backend with good test coverage.

---

## Phase 2 — Deployment Engine

* Docker
* Docker Compose
* Git integration
* Running shell commands safely
* Tracking deployment status

**Goal:** Deploy a simple application directly from the backend.

---

## Phase 3 — DevOps

* Cloudflare Tunnel
* Nginx or Caddy
* GitHub Actions
* Monitoring
* Logging

**Goal:** Create a production-style deployment workflow.

---

## Phase 4 — Platform Features

* Multiple projects
* Deployment history
* Rollbacks
* Environment variables
* Secrets
* Custom domains
* Health checks

**Goal:** Build a fully featured deployment platform.
